# C008 — PASS

**질문** 신용대출 금리 낮은 곳 추천해줘

core · 답한다

## 실행

- route: `product_recommendation`
- 호출: `recommend_credit_loan_products` {"credit_score": 700}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — PASS

- 신용대출 추천으로 라우팅한 뒤 신용대출 도구 호출. 사용자가 점수를 주지 않아 credit_score=700을 기본값으로 가정함(합리적)
- 결과 3건을 금리 순으로 정리(5.72%, 6.12%, 6.22%)하고 신용구간을 명시함
- 가드레일 적용 후 최종화. 흐름이 명확하고 효율적임

## ③ 답변 judge — PASS

- 신용대출 상품을 금리와 함께 안내: met - "농협은행주식회사의 '가계신용대출(마이너스대출)'로, 601~700점 신용구간에서 금리가 5.72%"
- 승인·한도 확정 표현 미사용: met - 승인·한도 언급 없음, "실제 가입 조건과 금리는 ... 최종 확정됩니다"
- exist_vs_unchecked: met - "현재 조회된 결과 중"
- absolute_claim: met - 단정 표현 없음
- unsupported_number: met - 5.72%, 6.12%, 6.22% source와 일치
- hidden_condition_change: met - "601~700점 신용구간에서" 기준 구간 공개
- unsupported_regulation: met - 규정 언급 없음

## 최종 답변

현재 조회된 결과 중 신용대출 금리가 가장 낮은 곳은 농협은행주식회사의 '가계신용대출(마이너스대출)'로, 601~700점 신용구간에서 금리가 5.72%입니다. 그 다음으로는 하나은행(6.12%), 우리은행(6.22%) 순입니다. ※ 실제 가입 조건과 금리는 상품설명서·약관 확인 후 최종 확정됩니다. 자세한 사항은 영업점 또는 고객센터에 문의하세요.

## 기대동작

- 신용대출 상품을 금리와 함께 안내한다
- 대출 승인이나 한도를 확정하는 표현을 쓰지 않는다
