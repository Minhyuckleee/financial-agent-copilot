# C020 — PASS

**질문** 농협 전세대출 금리 보여줘

core · 답한다

## 실행

- route: `product_recommendation`
- 호출: `recommend_jeonse_loan_products` {"bank_name_filter": "농협"}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — PASS

- 농협 금리 질의에 bank_name_filter="농협"으로 도구를 1회 호출했고 결과 3건을 받음
- 가드레일 통과 후 NH 상품 3개의 금리를 제시함
- 단계가 일관되고 효율적이며 목표를 달성함

## ③ 답변 judge — PASS

- behavior(농협 전세자금대출 안내): met — "NH전세대출(서울보증보험): 연 3.69% ~ 6.39%" 등 3개 상품을 모두 안내함
- exist_vs_unchecked: met — 조회 결과 안내
- absolute_claim: met — 없음
- unsupported_number: met — 모든 수치가 원자료에 있음
- hidden_condition_change: met — 해당 없음
- unsupported_regulation: met — 해당 없음

## 최종 답변

농협은행의 전세대출 금리는 다음과 같습니다.

- NH전세대출(서울보증보험): 연 3.69% ~ 6.39%
- NH전세대출(주택금융공사): 연 3.69% ~ 6.39%
- NH전세대출(주택도시보증공사): 연 3.7% ~ 6.4%

각 상품별로 금리 범위가 다소 차이가 있으니 참고하시기 바랍니다.

## 기대동작

- 농협 전세자금대출을 안내하거나, 조회되지 않으면 그렇다고 밝힌다
