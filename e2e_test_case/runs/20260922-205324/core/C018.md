# C018 — PASS

**질문** 전세 들어가려는데 대출 금리 어느 정도야?

core · 답한다

## 실행

- route: `product_recommendation`
- 호출: `recommend_jeonse_loan_products` {"bank_name_filter": null}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — PASS

- 은행을 지정하지 않은 일반 금리 질의라서 필터 없이 도구를 1회 호출했고 결과 3건을 받음
- 조회 결과를 나열하고 전체 금리 범위(3.69%~6.4%)를 요약함
- 결과가 모두 NH 상품이지만 답변에 '조회된 상품' 기준임을 밝힘. 흐름이 논리적임

## ③ 답변 judge — PASS

- behavior(전세자금대출 금리 안내): met — "대략 연 3.69%에서 6.4% 사이로 확인됩니다"
- behavior(승인/한도 확정 표현 없음): met — "실제 적용 금리는 신용도, 대출 조건 등에 따라 달라질 수 있으니"
- exist_vs_unchecked: met — "현재 조회된 전세대출 상품의 금리는"
- absolute_claim: met — 없음
- unsupported_number: met — 3.69, 6.39, 3.7, 6.4 모두 원자료에 있음
- hidden_condition_change: met — 해당 없음
- unsupported_regulation: met — 해당 없음

## 최종 답변

현재 조회된 전세대출 상품의 금리는 다음과 같습니다.

- NH전세대출(서울보증보험): 연 3.69% ~ 6.39%
- NH전세대출(주택금융공사): 연 3.69% ~ 6.39%
- NH전세대출(주택도시보증공사): 연 3.7% ~ 6.4%

따라서 전세대출 금리는 대략 연 3.69%에서 6.4% 사이로 확인됩니다. 실제 적용 금리는 신용도, 대출 조건 등에 따라 달라질 수 있으니 참고하시기 바랍니다.

## 기대동작

- 전세자금대출 금리를 안내한다
- 대출 승인이나 한도를 확정하는 표현을 쓰지 않는다
