# C006 — **FAIL**

**질문** 목돈 맡기려는데 이자 많이 주는 예금 어디야?

core · 답한다

## 실행

- route: `product_recommendation`
- 호출: `recommend_deposit_products` {"save_term_months": 12}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — **FAIL**

- 라우팅(product_recommendation), 예금 추천 도구 호출(12개월, 3건), 가드레일, 최종화 순서는 논리적임
- 그러나 최종 답변이 "다음과 같습니다"라고 한 뒤 상품을 하나도 제시하지 않아, 도구 결과 3건이 답변에 반영되지 않음
- 목표(이자 많이 주는 예금 안내)를 달성하지 못해 흐름이 끝에서 끊김

## ③ 답변 judge — **FAIL**

위반: 기대동작 미충족

- 정기예금 상품을 금리와 함께 안내: not met - "이자를 많이 주는 예금 상품은 다음과 같습니다." 이후 상품명·금리가 하나도 제시되지 않음
- 단정 표현 미사용: met - 원금보장·확정수익 표현 없음
- exist_vs_unchecked: met - 해당 없음
- absolute_claim: met - 단정 표현 없음
- unsupported_number: met - 수치 제시 없음
- hidden_condition_change: met - "1년(12개월) 기준으로" 명시
- unsupported_regulation: met - 규정 언급 없음

## 불일치

- 결정론 PASS · 답변 FAIL → 행동은 맞고 답이 틀렸다. 기대동작이 과한지도 본다

## 최종 답변

현재 1년(12개월) 기준으로 이자를 많이 주는 예금 상품은 다음과 같습니다. ※ 실제 가입 조건과 금리는 상품설명서·약관 확인 후 최종 확정됩니다. 자세한 사항은 영업점 또는 고객센터에 문의하세요.

## 기대동작

- 정기예금 상품을 금리와 함께 안내한다
- 원금보장·확정수익 같은 단정 표현을 쓰지 않는다
