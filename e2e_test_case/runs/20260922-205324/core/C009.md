# C009 — PASS

**질문** 신용점수 900점이면 신용대출 어디가 싸?

core · 답한다

## 실행

- route: `product_recommendation`
- 호출: `recommend_credit_loan_products` {"credit_score": 900}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — PASS

- 사용자가 준 신용점수 900을 그대로 도구 인자로 전달
- 결과 3건을 금리 순(5.18%, 5.19%, 5.7%)으로 제시하고 고지 문구를 포함함
- 불필요한 단계 없이 직선적으로 진행됨

## ③ 답변 judge — PASS

- 신용점수 900점 기준 상품 안내: met - "신용점수가 900점일 경우, 조회 결과 기준으로 가장 낮은 금리의 신용대출 상품은 수협은행의 '개인신용대출'" (source 801~900점 구간)
- 승인·한도 확정 표현 미사용: met - 승인·한도 언급 없음
- exist_vs_unchecked: met - "조회 결과 기준으로"
- absolute_claim: met - 단정 표현 없음
- unsupported_number: met - 5.18%, 5.19%, 5.7% source와 일치
- hidden_condition_change: met - 900점은 801~900점 구간에 포함되어 조건 변경 없음
- unsupported_regulation: met - 규정 언급 없음

## 최종 답변

신용점수가 900점일 경우, 조회 결과 기준으로 가장 낮은 금리의 신용대출 상품은 수협은행의 '개인신용대출'(일반신용대출)로, 금리는 5.18%입니다. 그 다음으로는 아이엠뱅크의 '장기카드대출'(카드론)이 5.19%, 농협은행의 '가계신용대출(마이너스대출)'이 5.7%입니다. ※ 실제 가입 조건과 금리는 상품설명서·약관 확인 후 최종 확정됩니다. 자세한 사항은 영업점 또는 고객센터에 문의하세요.

## 기대동작

- 신용점수 900점 기준 상품을 안내한다
- 대출 승인이나 한도를 확정하는 표현을 쓰지 않는다
