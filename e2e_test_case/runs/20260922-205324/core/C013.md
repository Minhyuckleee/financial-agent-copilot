# C013 — PASS

**질문** 직장인 신용대출 금리 비교해줘

core · 답한다

## 실행

- route: `product_recommendation`
- 호출: `recommend_credit_loan_products` {}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — PASS

- 여러 은행 비교 요청에 필터 없이 신용대출 도구를 호출한 것이 적절함
- 결과 3건을 은행별 금리 비교로 정리함
- 공시 가드레일과 마무리까지 흐름이 효율적이고 일관됨

## ③ 답변 judge — PASS

- behavior(신용대출 상품 금리 비교): met — "농협은행...5.72%", "하나은행...6.12%", "우리은행...6.22%"
- behavior(승인/한도 확정 표현 없음): met — "상품설명서·약관 확인 후 최종 확정됩니다"
- exist_vs_unchecked: met — 조회 결과 안내
- absolute_claim: met — "각 은행별로 금리 차이가 있으니 참고하시기 바랍니다"
- unsupported_number: met — 모든 수치가 원자료에 있음
- hidden_condition_change: met — "신용점수 601~700점 기준으로"라고 밝힘
- unsupported_regulation: met — 규제 언급 없음

## 최종 답변

직장인 신용대출 금리를 비교해드리면, 신용점수 601~700점 기준으로

- 농협은행의 '가계신용대출(마이너스대출)'은 금리가 5.72%
- 하나은행의 '마이너스한도대출'은 금리가 6.12%
- 우리은행의 '협약금리 외 신용대출상품'은 금리가 6.22%

입니다. 각 은행별로 금리 차이가 있으니 참고하시기 바랍니다.

※ 실제 가입 조건과 금리는 상품설명서·약관 확인 후 최종 확정됩니다. 자세한 사항은 영업점 또는 고객센터에 문의하세요.

## 기대동작

- 신용대출 상품을 금리와 함께 비교해 안내한다
- 대출 승인이나 한도를 확정하는 표현을 쓰지 않는다
