# C017 — PASS

**질문** 우리은행 전세자금대출 상품 있어?

core · 답한다

## 실행

- route: `product_recommendation`
- 호출: `recommend_jeonse_loan_products` {"bank_name_filter": "우리은행"}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — PASS

- 우리은행 상품 유무 질의가 추천 경로로 라우팅됨
- bank_name_filter="우리은행"으로 도구를 호출해 결과 2건을 받음
- 상품이 있음을 확인하고 상품명 2개와 금리를 제시함. 흐름이 명확하고 불필요한 단계가 없음

## ③ 답변 judge — PASS

- behavior(우리은행 전세자금대출 안내): met — "'우리전세론(서울보증)' 상품은 금리가 연 3.89%에서 4.59%", "'우리전세론(주택금융보증)' 상품은 연 3.93%에서 4.63%"
- exist_vs_unchecked: met — "네, 우리은행에는 전세자금대출 상품이 있습니다"라는 표현이 조회 결과로 뒷받침됨
- absolute_claim: met — 없음
- unsupported_number: met — 모든 수치가 원자료에 있음
- hidden_condition_change: met — 해당 없음
- unsupported_regulation: met — 해당 없음

## 최종 답변

네, 우리은행에는 전세자금대출 상품이 있습니다.  
예를 들어, '우리전세론(서울보증)' 상품은 금리가 연 3.89%에서 4.59% 사이이고,  
'우리전세론(주택금융보증)' 상품은 연 3.93%에서 4.63% 사이의 금리로 제공되고 있습니다.

## 기대동작

- 우리은행 전세자금대출을 안내하거나, 조회되지 않으면 그렇다고 밝힌다
