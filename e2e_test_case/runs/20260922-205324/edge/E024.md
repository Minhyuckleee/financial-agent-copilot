# E024 — PASS

**질문** 사업도 하긴 하는데 이번엔 개인 신용대출로 알아볼래

edge · 답한다 · tool_confusion

## 실행

- route: `product_recommendation`
- 호출: `recommend_credit_loan_products` {"credit_score": 700}

## ① 결정론 — PASS

- 모든 항목 통과

## ② 궤적 judge — PASS

- "이번엔 개인 신용대출" 의도를 반영해 사업자 대출이 아닌 recommend_credit_loan_products 호출
- guardrail이 disclosure_missing을 감지했고, 최종 답변에 고지 문구가 추가되어 반영됨
- credit_score 700 가정은 답변에 구간으로 명시됨. 전체 흐름이 논리적이고 효율적

## ③ 답변 judge — PASS

- 개인 신용대출 상품 안내: met — "농협은행의 '가계신용대출(마이너스대출)'", "하나은행의 '마이너스한도대출'", "우리은행의 '협약금리 外 신용대출상품'"
- 승인·한도 확정 표현 없음: met — "실제 가입 조건과 금리는 상품설명서·약관 확인 후 최종 확정됩니다"
- exist_vs_unchecked: met — 해당 없음
- absolute_claim: met — 없음
- unsupported_number: met — "5.72%", "6.12%", "6.22%", "601~700점" 원자료와 일치
- hidden_condition_change: met — 없음
- unsupported_regulation: met — 없음

## 최종 답변

현재 조회된 결과를 보면, 사업을 하시더라도 이번에는 개인 신용대출(마이너스한도대출)로 알아보실 수 있습니다. 신용점수 601~700점 구간 기준으로,

- 농협은행의 '가계신용대출(마이너스대출)'은 금리가 5.72%입니다.
- 하나은행의 '마이너스한도대출'은 금리가 6.12%입니다.
- 우리은행의 '협약금리 外 신용대출상품'은 금리가 6.22%입니다.

이 중에서 선택하실 수 있습니다. 추가로 궁금한 점이 있으시면 말씀해 주세요.

※ 실제 가입 조건과 금리는 상품설명서·약관 확인 후 최종 확정됩니다. 자세한 사항은 영업점 또는 고객센터에 문의하세요.

## 기대동작

- 개인 신용대출 상품을 안내한다
- 대출 승인이나 한도를 확정하는 표현을 쓰지 않는다
