# Financial-Agent-Copilot

은행 상담직원용 업무보조 AI 에이전트 — 상품추천·환율조회·사내규정질의를 자연어로 처리하는 CLI 기반 Agent.

## 핵심 요약

- **Agent 설계·구현** — LangGraph StateGraph로 라우팅→컨텍스트구성→tool call→가드레일→answer 5단계 그래프 구현
- **의도·대화상태 라우팅** — 4클래스 분류 + 대화이력 반영 + 저신뢰 시 재작성 복구(Tier0)
- **컨텍스트 조합** — 대화이력 재사용(멀티턴) + RAG 검색결과 + tool 호출 결과(API 응답)를 결합해 답변 생성
- **Tool/API 예외처리** — 실API 6개 연동. Tier1(라우팅·tool선택은 맞다고 전제, 외부 API 자체 문제 — fail/delay)·Tier2(API는 정상인데 Agent의 해석이 잘못됐을 가능성 — 결과없음/파라미터무효/tool미선택) 두 계층으로 나눠 재시도·복구
- **가드레일** — 5규칙 자동교정(PII마스킹/필수고지/금지표현/숫자검증/citation grounding)
- **테스트셋 기반 품질개선** — 복합 시나리오 520건 Agent 정확도 평가, 88.2%→96.9% (프롬프트 보강 및 가드레일 수정)

## Agent 구조도

```
router.py
  → context.py   (사내규정질의일 때만 실행)
  → tool_call.py (상품추천/환율조회일 때만 실행)
  → guardrail.py
  → answer.py
```

라우터가 발화를 4클래스(상품추천/환율조회/사내규정질의/범위외)로 분류하면, context와 tool_call은 항상 순서대로 지나가되 해당 없는 route에선 즉시 빠져나갑니다 — 향후 RAG+tool을 동시에 써야 하는 하이브리드 route로 확장할 여지를 열어두기 위한 선택이고, 실행비용 차이는 없습니다. 자세한 내용은 [src/graph/README.md](src/graph/README.md)를 참고해 주세요.

## 주요 기능

### 상품추천

정기예금·신용대출·전세자금대출·주택담보대출·개인사업자대출 5종, 금융감독원 「금융상품한눈에」 실API 기반.

```
질문: 전세자금대출 상품 알아봐줘
답변: 현재 조회된 전세자금대출 상품은 농협은행에서 제공하는 상품들입니다. 상품명과 금리는 다음과 같습니다.

1. NH전세대출(서울보증보험): 금리 연 3.28% ~ 5.98%
2. NH전세대출(주택금융공사): 금리 연 3.28% ~ 5.98%
3. NH전세대출(주택도시보증공사): 금리 연 3.28% ~ 5.98%

모두 농협은행에서 취급하며, 금리는 상품별로 동일하게 조회되었습니다.
```

### 환율조회

원/달러 환율, 한국은행 ECOS 실API 기반.

```
질문: 환율 알려줘
답변: 현재 USD/KRW 환율은 1397.7원입니다. (기준일: 2026.08.19)
```

### 사내규정질의

개인정보보호·전자금융·금융상품 설명의무·마이데이터·예금거래약관 등 13개 문서 기반 RAG 검색.

```
질문: 예금거래기본약관은 은행 영업점에서 언제 볼 수 있나요?
답변: 문서에 따르면, 예금거래기본약관을 은행 영업점에서 열람할 수 있는 시간에 대해 다음과 같이 규정하고 있습니다:

"은행은 이 약관을 영업점에 놓아두고, 거래처는 영업시간 중 언제든지 이 약관을 볼 수 있고 또한 그 교부를 청구할 수 있다."

따라서, 예금거래기본약관은 은행 영업점의 영업시간 중에 열람할 수 있습니다.
```

### 대화이력 반영(멀티턴)

이전 턴에서 확정된 조건을 후속 발화에도 재사용합니다.

```
질문(1턴): 정기예금 좋은 상품 추천해줘
답변(1턴): 12개월 기준 정기예금 상품 3건을 안내드립니다.

질문(2턴): 6개월짜리로 다시 봐줘
답변(2턴): 6개월짜리 예금 상품의 금리는 다음과 같습니다.

- 전북은행의 'JB 다이렉트예금통장(만기일시지급식)'은 기본금리와 우대금리 모두 연 3.45%입니다.
- 한국스탠다드차타드은행의 'e-그린세이브예금'은 기본금리 3.2%, 우대금리 3.4%입니다.
- 농협은행의 'NH왈츠회전예금 II'는 기본금리 2.95%, 우대금리 3.05%입니다.

이렇게 세 가지 상품이 있습니다.
```

"12개월"이라는 조건 언급 없이 "6개월짜리로 다시 봐줘"라고만 말해도, 이전 턴에서 조회한 상품군(정기예금)이 뭐였는지를 기억해 기간 조건만 바꿔 재조회합니다.

## 가드레일

답변을 내보내기 전 5규칙을 자동교정으로 통과시킵니다(사람 개입 없음).

| 규칙 | 내용 | 메커니즘 |
| --- | --- | --- |
| ① PII 마스킹 | 주민번호/카드번호/계좌번호 | 정규식, 숫자 앞 두자리만 남기고 마스킹 |
| ② 필수고지 자동삽입 | 상품 설명 시 법정 고지문구 누락 방지 | 규칙기반 |
| ③ 금지표현 차단 | "원금보장"/"확정수익" 등 과장·단정 표현 | 사전 매칭 + LLM semantic 탐지 |
| ④ 숫자 자체검증 | 답변 속 숫자를 원본 API값과 대조 | route별 정규식 또는 LLM 추출 |
| ⑤ citation grounding | RAG 인용 주장이 검색문서로 실제 뒷받침되는지 | LLM entailment 판정 |

위반이 발견되면 해당 문구가 포함된 문장을 통째로 제거합니다(단어만 지우면 문법이 깨지는 문제를 방지). 규칙 하나가 걸려도 나머지 규칙을 계속 실행하는 전량검사 방식입니다. 자세한 내용은 [src/graph/README.md](src/graph/README.md)를 참고해 주세요.

### 실제 작동 예시

**①PII 마스킹** — 답변에 계좌번호가 우연히 섞여도 자동으로 마스킹됩니다.

```
수정 전: 계좌번호 110-234-567890로 예금 가능합니다.
수정 후: 계좌번호 11**********로 예금 가능합니다.
```

**②필수고지 자동삽입** — 상품 추천 답변 끝에는 아래 고지문구가 항상 따라붙습니다(누락되면 이 규칙이 채워넣습니다).

```
질문: 정기예금 좋은 상품 추천해줘
답변: (상품 목록 안내) ...
※ 실제 가입 조건과 금리는 상품설명서·약관 확인 후 최종 확정됩니다. 자세한 사항은 영업점 또는 고객센터에 문의하세요.
```

**③금지표현 차단** — "제일", "가장" 같은 최상급 표현을 유도하는 질문에도 단정적 표현 없이 사실(수치)만 안전하게 답합니다.

```
질문: 제일 좋은 예금 상품 하나만 추천해줘
답변: 12개월 기준 기본 금리는 연 3.65%이고, 우대금리까지 포함하면 최대 연 3.85%의 이자를 받을 수 있습니다.
```

**④숫자 자체검증** — 답변 속 숫자가 원본 데이터와 다르면 실제 값으로 바로잡습니다.

```
수정 전: 국민은행 정기예금A 금리는 3.9%이고, 우리은행 정기예금B 금리는 3.9%입니다.
수정 후: 국민은행 정기예금A 금리는 3.8%이고, 우리은행 정기예금B 금리는 3.9%입니다.
```

**⑤citation grounding** — 답변 속 인용 주장이 실제 검색 문서로 뒷받침되는지 대조합니다. 근거가 있으면 문서 원문을 그대로 인용해 답합니다.

```
질문: 전화로 개인정보 수집 동의를 받아도 되나요?
답변: 네, 전화 통화를 통해 개인정보 수집에 대한 동의를 받는 것은 관련 법령상 허용됩니다.

문서에서는 다음과 같이 명시하고 있습니다:
"개인정보처리자는 전화상으로 개인정보 수집에 대한 정보주체의 동의를 받을 수 있다. 다만 향후 입증책임 문제가 발생할 수 있으므로 정보주체가 개인정보 수집·이용에 동의한다는 통화내용을 녹취할 수 있다."
```

## 예외처리

| Tier | 대상 | 판단 | 처리 |
| --- | --- | --- | --- |
| Tier0 | 라우팅 | 1차 분류가 범위외로 나옴 | history 참고해 재작성 후 1회 재분류, 실패하면 정직하게 범위외로 확정 |
| Tier1 | API 레벨 | 호출 자체가 실패(fail) 또는 지연(delay) | fail은 같은 조건으로 최대 1회 재시도, delay는 재시도 없이 즉시 포기 |
| Tier2 | 해석 레벨 | API는 정상인데 결과 없음 / 파라미터 무효 / tool 미선택 | LLM이 파라미터를 다시 해석해 최대 1회 재시도, 실패하면 가드레일을 생략하고 실패 사유를 반영한 정직한 안내문을 생성 |

### 실제 작동 예시

**Tier0(라우팅 재작성)** — "왜 그래요?"처럼 극단적으로 생략된 후속질문은 1차 분류가 실패하기 쉽습니다. history를 참고해 재작성한 뒤 재분류하면 복구됩니다.

```
이전 대화: "금융상품 설명의무는 뭘 설명해야 하나요?" → "일반금융소비자에게 중요사항을 이해할 수 있도록 설명해야 합니다."
질문: 왜 그래요?
답변: 금융상품 설명의무에서 일반금융소비자에게 중요사항을 설명해야 하는 법적 근거는 금융소비자보호법 제19조(설명의무) 제1항입니다.
정보열위에 있는 소비자가 거래결과에 스스로 책임질 수 있도록 필요한 정보를 제공하는 데 그 취지가 있습니다.
```

**Tier1(API fail 재시도)** — 강제로 1회 실패시킨 뒤에도, 같은 조건으로 재시도해 정상 결과를 반환합니다.

```
질문: 정기예금 좋은 상품 추천해줘 (1차 호출 강제 실패 → 재시도)
답변: 현재 가입할 수 있는 정기예금 상품 중에서 추천드릴 만한 상품은 다음과 같습니다.
1. 한국스탠다드차타드은행의 'e-그린세이브예금' — 12개월, 기본금리 연 3.65%, 우대금리 적용 시 연 3.85%
2. 전북은행의 'JB 123 정기예금(만기일시지급식)' — 12개월, 기본금리 연 3.21%, 우대금리 적용 시 연 3.81%
```

**Tier2(파라미터 재해석)** — "신한은행 18개월 정기예금"은 API에 없는 조건이라 1차 조회가 빈 결과로 돌아옵니다. LLM이 조건을 12개월로 재해석해 재조회하고, 원래 조건이 무엇이었는지 숨기지 않고 답변에 그대로 밝힙니다.

```
질문: 신한은행 18개월 정기예금 추천해줘
답변: 현재 조회 결과에 따르면 신한은행의 18개월 정기예금 상품 정보는 확인되지 않습니다. 대신, 신한은행에서 12개월(1년) 정기예금 상품으로는 '신한My플러스 정기예금'(최고 연 3.2%)과 '쏠편한 정기예금'(최고 연 3.2%)이 있습니다. 18개월 상품이 필요하시다면 신한은행에 직접 문의해 보시거나, 추가 정보를 확인해 보시는 것이 좋겠습니다.
```

## Agent 평가 

기능별 최소 1건씩만 확인하는 평가로는 실제 문제를 못 잡는다는 걸 깨닫고, 여러 조건이 동시에 겹치는 복합 시나리오 520건(개발용 416건 + 개발에 안 쓴 별도 검증용 104건)으로 평가셋을 확장했습니다.

- 개발용 416건: 1차 실행 88.2%(367/416) → 실패 49건을 전수조사해 진짜 코드버그 4건만 골라 수정(나머지는 테스트케이스 설계오류로 판명, 같이 수정) → 재실행 96.9%(403/416)
- 별도 검증용 104건: 1차 실행 98.1%(102/104) → 실제 코드결함 2건 수정 + 골든셋 라벨 오류 1건 정정 → 최종 100%(104/104)

단순 최종 수치가 아니라, 실패를 원인별(진짜버그 vs 테스트설계오류)로 정직하게 갈라서 각각 고치고 그 수정이 개발에 안 쓴 문항에도 통하는지 재검증한 과정이 핵심입니다. RAG 검색 자체는 별도로 결정론적 지표(Recall/Precision/MRR)와 RAGAS 4종을 측정합니다. 전체 지표와 실험과정은 [scripts/README.md](scripts/README.md)를 참고해 주세요.

## 실행 가이드

```bash
git clone <repo-url>
cd financial-agent-copilot
pip install -e .

cp .env.example .env
# .env에 OPENAI_API_KEY / FINLIFE_API_KEY / ECOS_API_KEY 입력

python src/cli.py
```

RAG 인덱스는 `data/rag/`에 이미 빌드돼 포함돼있어 별도 빌드 없이 바로 실행 가능합니다.

테스트 실행:

```bash
pip install -e ".[dev]"
PYTHONPATH=src pytest
```
